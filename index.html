LEVEL01 - SUBNETTING BASICS

how many usable hosts are in /26 network?

A /26 network has 6 host bits. 2^6 = 64 total addresses. Subtract the network and broadcast addresses, leaving 62 usable host addresses.

LEVEL 02 - NETWORK ADDRESS

what is the network address of 192.168.1.70/26?

A /26 subnet contains 64 addresses. The subbnet ranges are 0-63, 64-127, 128-191 and 192-255. Since 70 falls between 64 and 127, the network address is 192.168.1.64.
